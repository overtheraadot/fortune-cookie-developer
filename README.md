A make.fun entry for the "Fortune Cookie Wisdom for Developers" bounty: a
Python program that writes one original fortune-cookie line for a software
developer — about the legacy code we curse and the Friday ship that wrote it —
to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt`. With `MAKEFUN_OUTPUT_DIR` unset it writes to
`/output/entry.txt`. Standard library only, no network, fully deterministic.
